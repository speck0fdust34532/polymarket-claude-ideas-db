# Polymarket & Kalshi 15-Minute Arbitrage Bot

## Project Overview
An open-source trading bot designed to detect and exploit price differences between Polymarket and Kalshi specifically for 15-minute crypto and event markets.

## Key Features
- **Cross-Platform Monitoring:** Tracks real-time odds on both Polymarket (Polygon) and Kalshi (CFTC-regulated).
- **Latency Optimization:** Optimized for rapid execution in 15-minute intervals.
- **Automated Execution:** Executes trades when a specific arbitrage spread is detected (e.g., >1.5%).
- **Risk Management:** Includes built-in stop-losses and inventory management.
