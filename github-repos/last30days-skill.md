# last30days-skill: AI Agent Research Skill

## Repository Overview
**last30days-skill** is an AI agent skill that researches any topic across Reddit, X, YouTube, HN, Polymarket, and the web, then synthesizes a grounded summary.

## Key Features
*   **Multi-Platform Research**: Searches across social media, news, and prediction markets.
*   **Grounded Summaries**: Synthesizes a comprehensive summary of the researched topic.
*   **Topic Analysis**: Can be used to research market sentiment, news, and trends.

## Strategy Context
This skill can be integrated into a larger AI trading system (like a two-layer brain-hands architecture) to provide the "brain" with a comprehensive research and synthesis capability for informed trading decisions.
