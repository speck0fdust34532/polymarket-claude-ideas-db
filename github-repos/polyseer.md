# Polyseer: Open-source AI Research Platform

## Platform Overview
Polyseer is an open-source AI research platform that provides systematic evidence-based analysis for Polymarket and Kalshi prediction markets using multi-agent architecture, Bayesian probability aggregation, and real-time data sources to generate comprehensive reports with mathematical confidence scores.

## Key Features
- **Multi-Agent Architecture:** Uses multiple specialized agents to analyze Polymarket and Kalshi markets.
- **Bayesian Probability Aggregation:** Combines signals from different agents using Bayesian methods to reach a final probability.
- **Evidence-Based Analysis:** Generates reports based on systematic analysis of real-time data sources.
- **Mathematical Confidence Scores:** Provides a quantified confidence level for each prediction.
