# last30days-skill: Multi-Platform AI Research Tool (2026)

## Repository Overview
**last30days-skill** is a specialized AI agent skill designed to conduct deep, cross-platform research across six major social and news platforms: Reddit, X, YouTube, Hacker News, Polymarket, and the general web. It synthesizes these findings into a grounded, actionable summary for prediction market analysis.

## Key Features
- **Multi-Source Synthesis:** Simultaneously aggregates sentiment and news from multiple platforms to provide a 360-degree view of any topic.
- **Grounded Summaries:** Moves beyond generic LLM "hallucinations" by citing specific, recent data points and trends from live sources.
- **Topic Analysis:** Ideal for identifying emerging market sentiment and news stories that haven't been fully priced into Polymarket or Kalshi.

## Strategic Context: The "Research Engine"
In a **Two-Layer AI System**, this tool serves as the critical "Research Engine." It feeds the "Brain" (Claude 4.5) with real-time, cross-platform context, allowing for superior probability estimation and the detection of mispriced contracts.

## Technical Implementation
- **Platform Coverage:** Reddit, X, YouTube, HN, Polymarket, Web.
- **Output Format:** Structured Markdown summaries with source citations.
- **Integration:** Can be used as a standalone tool or integrated into autonomous agent frameworks like OpenClaw or CloddsBot.
