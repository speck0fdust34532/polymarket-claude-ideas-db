# last30days-skill: AI Agent Research Tool (2026)

## Repository Overview
**last30days-skill** is a specialized AI agent skill designed to conduct deep research across multiple social and news platforms (Reddit, X, YouTube, HN, Polymarket, and the general web) and synthesize the findings into a grounded, actionable summary.

## Key Features
- **Multi-Source Synthesis:** Aggregates sentiment and news from six major platforms simultaneously.
- **Grounded Summaries:** Moves beyond generic LLM "vibes" by citing specific, recent data points and trends.
- **Topic Analysis:** Ideal for researching market sentiment, emerging news stories, and trend analysis for prediction markets.

## Strategy Context
This tool is a critical component for any "Two-Layer" AI trading system. It serves as the "Research Engine" that feeds the "Brain" (Claude 4.5) with real-time, cross-platform context, allowing the system to identify mispriced contracts before they become mainstream.

## Technical Implementation
- **Platform Coverage:** Reddit, X, YouTube, Hacker News, Polymarket, Web.
- **Output Format:** Structured Markdown summaries with source citations.
- **Integration:** Can be used as a standalone tool or integrated into autonomous agent frameworks like OpenClaw or CloddsBot.
