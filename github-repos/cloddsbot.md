# CloddsBot: Autonomous AI Trading Agent

## Repository Overview
**CloddsBot** is an open-source AI trading agent that operates autonomously across multiple markets, including Polymarket, Kalshi, Binance, Hyperliquid, Solana DEXs, and several EVM chains.

## Key Features
*   **Autonomous Operation**: Operates across 1000+ markets without manual intervention.
*   **Multi-Platform Support**: Connects to both centralized and decentralized prediction markets and exchanges.
*   **AI-Driven Decision Making**: Uses advanced AI models to analyze market signals and execute trades.
*   **Cross-Chain Capability**: Supports 5 EVM chains and Solana.

## Technical Stack
*   **Platform Support**: Polymarket, Kalshi, Binance, Hyperliquid, Solana DEXs, EVM chains.
*   **Market Reach**: 1000+ markets.

## Strategy Context
CloddsBot is a practical implementation of an autonomous trading agent that can be used for market making, arbitrage, and momentum trading across various platforms.
